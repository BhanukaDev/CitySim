# Water simulation: credits

`water.cpp` is original code (CitySim). It implements the "virtual pipes" shallow-water model described in:

- J. F. O'Brien and J. K. Hodgins, "Dynamic Simulation of Splashing Fluids", Computer Animation 1995.
- X. Mei, P. Decaudin and B.-G. Hu, "Fast Hydraulic Erosion Simulation and Visualization on GPU", Pacific Graphics 2007
  (the pipe model section; no erosion here).

No third-party code is included.
