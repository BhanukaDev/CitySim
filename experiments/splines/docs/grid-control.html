Splines · S6 · Grid mode rethink

Grid follows the cursor

Right now the block size is fixed, so the grid's outline jumps in whole blocks (74 m at 8 × 8 lots) and never sits where you put the mouse. The idea here: the outline goes exactly where you drag, and you choose how many roads or how dense the grid is inside it. Every block shows its size so you can see what zoning will get.

Rules I'd add

The outline is yours

  • The far corner is the cursor, with the usual snaps (nodes, guides, length steps with Ctrl).
  • The roads inside never move the outline.
  • The tag shows the outline size and the block count: 3 × 2 blocks · 236 × 152 m.

Smallest block

  • A block needs at least 2 lots (16 m) of clear space, one lot deep from each side.
  • In A, + stops at that size. In B, the count drops a block instead.
  • Too small an outline for even one block is red and refused (unless Anarchy).

Block labels

  • Each block shows its clear size in m and in lots while you draw.
  • Green: whole lots. Amber: a part lot is left over, so zoning leaves a strip unused.
  • Labels hide when a block is too small on screen; the tag still has the range.
