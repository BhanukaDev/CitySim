# Icons

From [Tabler Icons](https://tabler.io/icons) v3.34.1 (outline set), MIT licence, Copyright (c) 2020-2024 Paweł Kuna.
Changes: stroke colour set to white (so the UI can tint them) and size set to 64 px (crisp when scaled).

To add one: download `https://cdn.jsdelivr.net/npm/@tabler/icons@3.34.1/icons/outline/<name>.svg` and apply the same two edits.

`channel-v`, `channel-u`, `channel-flat` and `channel-box` are our own, drawn in the same style (24 grid, 2 px round stroke).
